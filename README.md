# java-concepts

Hands-on Java learning repository — from core Java fundamentals to advanced concepts. Every concept is practiced with code, documented, and committed.

**Target:** Strong Java fundamentals for Software Engineering / Backend Development roles  
**Method:** Learn → Code → Practice → Document → Commit

No theory without code. Every concept in this repository is backed by Java examples and practical exercises.

---

## How this repo is structured

Every topic has its own folder.

Inside each folder:

- `README.md` — concept explanation, key takeaways, and examples
- `*.java` files — hands-on Java programs
- Practice examples — small programs to understand the concept
- Exercises — additional problems where applicable

The goal is not just to memorize Java syntax, but to understand how Java concepts work and be able to explain them in interviews.
